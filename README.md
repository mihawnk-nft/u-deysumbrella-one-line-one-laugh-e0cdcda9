## What it does

`main.py` (pure Python standard library, no dependencies) writes a single original funny line — at most 140 characters — to `/output/entry.txt`:

> My smart fridge keeps suggesting salads, so I unplugged it — I don't need judgment from something that holds my ice cream.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
